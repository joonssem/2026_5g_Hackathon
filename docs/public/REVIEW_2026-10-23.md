# 개인정보·구조·수업 흐름 점검 · 2026-10-23

현재 폴더의 공개 파일·로컬 보관 문서·숨김 설정과 로컬 Git 이력을 대상으로 점검했습니다. 발견한 상충 내용은 아래와 같이 정정했습니다. 실제 Padlet 제출 링크와 학생 접속 QR코드는 유지했습니다.

## 개인정보와 공개 범위

| 확인 대상 | 결과 |
| --- | --- |
| 학생 이름·출석번호·결석 정보 | 현재 파일에서 개인과 연결된 기록을 발견하지 못함 |
| 로컬 설문·조 편성 자료 | 개인별 대응표 없이 익명 집계와 일반 편성 기준만 남아 있음 |
| 연락처·주민번호 형태·인증키 | 현재 일반 파일의 패턴 검사에서 발견하지 못함. 이름·맥락은 문서 수동 검토 병행 |
| 공개 파일의 1번·2번·3번 | 팀 안의 역할 순서. 실제 출석번호가 아님을 안내에 명시 |
| 운영 주소 | 유지 요청된 Padlet 제출 양식과 학생 접속 QR 주소에는 서비스 계정 식별자가 포함됨. 삭제 대상인 학생 개인정보와 구분하여 유지 |
| Git 작성자·로컬 이력 | 작성자는 일반 이름과 예시 이메일. 접근 가능한 커밋 이력의 변경 내용에서 학생별 원문·출석번호·출결 연결 기록을 발견하지 못함 |
| 과거 커밋의 설문·조 편성 문서 | 익명 집계·일반 기준이 남아 있음. 학생 식별 정보가 없으면 이력은 유지한다는 사용자 지시에 따름 |
| 외부 서비스·브라우저 | 실제 Canva·Padlet 게시물, 계정 프로필, 브라우저에 저장된 입력값은 이번 파일 검사 대상이 아님 |

`noindex`는 검색 노출을 줄이는 표시이며 접근 제한이 아닙니다. 학생이 쓰는 자유 입력에 개인정보가 들어오면 자동으로 익명화하지 않습니다. 글과 화면을 공유하기 전 팀원·교사가 직접 확인합니다.

## 파일 구조

| 위치 | 역할 | 공개 범위 |
| --- | --- | --- |
| `index.html`, `app.js`, 학생용 CSS | 9단계 수업·기기별 로컬 기록·요청문·제출 본문 생성 | GitHub 공개 |
| `teacher.html`, `teacher.js`, `teacher.css` | 교실 앞 6장 시작 안내 | GitHub 공개 |
| `config.js`, `assets/` | 반별 제출 링크·학생 접속 QR | 유지 요청에 따라 공개 |
| `docs/README.md`, `docs/public/` | 일반 운영·설계·검증·점검 문서 | GitHub 공개 |
| `docs/private/` | 설문 집계·조 편성 관련 로컬 문서 | Git 추적 제외 |
| `tests/` | 상태·이벤트와 전자칠판 동작 검사 | GitHub 공개 |
| `scratch/` | 임시 검사 도구 | Git 추적 제외 |

공개·비공개 폴더 분리와 `.gitignore`는 일치합니다. 폴더 전체 복사·압축·일반 HTTP 서버에는 Git 제외 규칙이 적용되지 않으므로 별도 전달·배포 시에는 공개 파일만 선택합니다. 로컬 문서 제외는 접근 잠금이나 암호화를 뜻하지 않습니다.

## 정정한 상충·누락

| 중요도 | 발견 내용 | 정정 |
| --- | --- | --- |
| 높음 | 감상 단계에서 Reader로 바꾸면서 댓글·좋아요를 요구 | 감상 중 Commenter와 댓글·반응 허용, 감상 종료 후 필요 시 Reader 적용 |

| 보통 | 3인 팀도 두 기기를 쓰는데 조원 모두 자기 기기에서 문서를 열도록 요구 | 3번은 1번 화면을 함께 보고, 별도 기기를 쓰는 경우에만 추가 계정 초대 |
| 보통 | 게시 주소 입력란이 팀 이름과 같은 100자 제한 | URL 전용 입력과 2048자 한도로 변경. 긴 실행 주소의 저장·복원·복사 검증 |
| 보통 | 공유 문서의 최종 링크를 안내 웹에 넣는 단계가 생략되고 양식을 먼저 열도록 안내 | 최종 주소 입력 → 반·팀·내용 확인 → 새 탭 양식 → 항목별 복사 → 게시 순서로 정리 |
| 보통 | 검증 문서의 배포 미완료·Padlet 미설정·초기 인증 실패가 현재 상태처럼 남음 | 현재 검증 범위로 재작성하고, 과거 실패는 날짜별 제작 기록과 구분 |
| 낮음 | 전자칠판 시작 안내가 5단계의 문서 생성을 먼저 하라는 의미로 읽힐 수 있음 | 먼저 1단계 불편 발견 흐름에 들어가고 문서 공유는 5단계에서 안내하도록 표시 |
| 낮음 | 경험 탐색을 강조하면서 교사용 메모는 예시를 골라 일부만 바꾸도록 지시 | 장면 힌트로 자신의 경험을 말·그림으로 표현하도록 정리 |
| 낮음 | 도구의 로그인 금지 조건이 Canva 수업 로그인과 혼동 가능 | 금지 조건은 학생이 제작할 웹 도구의 기능 범위임을 명시 |
| 낮음 | README의 상대 링크가 GitHub 파일 화면으로 연결되고 중복 문구·글자 크기 설명이 부정확 | 실제 활동 주소와 전자칠판 주소, 현재 CSS 수치로 정리 |

Padlet 권한과 수동 검토의 근거는 [방문자 권한 안내](https://padlet.help/l/en/article/l2d9pcbd9i-privacy-settings), [게시물 숨김 안내](https://padlet.help/l/en/article/27gow0dbq7-how-can-i-hide-posts)에서 확인했습니다. 문서 공동 편집의 근거는 [Canva Docs 공유 안내](https://www.canva.com/help/share-publish-docs/)에서 확인했습니다.

## 순서와 기록의 연결

| 단계 | 앞에서 가져올 내용 | 이 단계의 결과·다음 연결 |
| --- | --- | --- |
| 01 함께 출발 | 교사 시작 안내·QR 접속 | 팀 역할·반·팀 이름 결정 |
| 02 불편 발견 | 각 팀원의 경험 | 개인 이름 없이 상황 기록 |
| 03 문제 선택 | 앞 단계의 상황 | 사용자·문제·선택 이유·원하는 변화 |
| 04 해결 탐색 | 선택한 문제 | 방법 A/B·선택한 방법·선택 이유 |
| 05 프롬프트 완성 | 사용자·문제·목표·해결 방법 | 입력·행동·결과·성공 기준 → 요청문 → Canva 공유 문서 |
| 06 Canva 구현 | 공유 문서의 요청문 | 2번이 구현·게시 → 문서에 실행 링크 |
| 07 시험과 개선 | 실행 링크·성공 기준 | 1번이 시험 → 문서로 수정 요청 → 2번 수정·재게시 → 재시험 |
| 08 Padlet 나눔 | 확정한 실행 링크·문제·탐색·시험 기록 | 최종 입력 검토 → 반별 제출 → 교사 승인·별도 감상 |
| 09 생각 돌아보기 | 팀 대화·시험·공개 여부에 맞는 친구 의견 | 성찰·다음 개선점·전체 기록 보관 |

01~05단계는 40분, 06~09단계는 40분으로 앱·README·교사 운영표가 일치합니다. Canva 공유 문서의 수정은 안내 웹의 입력값을 자동 변경하지 않으며, Padlet 본문은 안내 웹에 기록한 내용을 사용합니다. 따라서 확정한 요청문과 시험 기록은 양쪽에 필요한 내용을 직접 복사해야 합니다.

## 남은 현장 확인

- 5단계 13분에 기획과 공유 초대까지 마칠 수 있는지 확인. 초대 시범 또는 교사 사전 문서 준비 권장.
- 학교 계정의 Canva Code·문서 초대·공동 편집 권한과 실제 게시·재게시 확인.
- 실제 Padlet에서 제출 중 노출, 제출 후 이동, 승인·감상·댓글·좋아요 확인.
- iPad Safari와 65인치 전자칠판의 실제 가독성·복사 대안·다운로드 확인.

자동 검사와 한계는 [검증 기록](VALIDATION.md)에 정리했습니다. Canva·Padlet의 외부 계정 설정은 이 점검에서 변경하지 않았으며, 소스의 커밋·푸시와 실제 서비스 설정은 구분합니다.

최종 실행에서는 임시 검사 도구를 포함한 일반 파일 23개와 문서·HTML의 로컬 참조 21개를 확인했습니다. 연락처·주민번호 형태·인증키 패턴 발견 0건, JavaScript 구문 검사·학생 흐름 테스트·전자칠판 테스트·Git 무결성 검사 모두 통과했습니다. 실제 Padlet 설정과 QR 자산은 변경하지 않았습니다.
