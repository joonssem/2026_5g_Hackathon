# 검증 기록 · 2026-10-23

이 문서는 현재 소스의 검증 범위를 설명합니다. 과거 개발 중의 권한·연결 실패는 [제작 기록](DESIGN_LOG.md)에 남기고 현재의 미완료 항목과 구분합니다. 소스 검증과 원격 배포 완료는 별도로 확인합니다.

## 확인한 항목

- JavaScript 구문: `app.js`, `config.js`, `teacher.js`.
- 학생 흐름: 9단계 이동, 2인·3인 전환, 기존 기록 유지·복원·초기화, 저장소 실패 안내, 사용자 문자열의 HTML 이스케이프.
- 기록 전달: 입력한 문제·목표·해결 방법·입력·행동·출력·성공 기준이 요청문에 반영되고, 시험 결과·수정 요청이 Padlet 본문까지 이어짐.
- 복사: 요청문·수정 요청·기록·Padlet 제목·실행 링크·본문을 각 목적에 맞게 구분. 길이가 100자를 넘는 실행 링크의 입력 한도·저장·복원·복사 확인.
- 설정: 1~4반의 실제 제출 양식 링크가 반 선택에 따라 바뀌며, 미등록 반은 연결을 보류. HTTPS Padlet 주소 허용과 잘못된 URL 거부.
- 감상: `padletViewUrl`이 비어 있으면 전체 보기 버튼을 숨기고, 설정한 경우 별도 감상 버튼을 표시.
- 시간: 01~05단계 4+8+6+9+13=40분, 06~09단계 18+8+10+4=40분. 교사 진행표와 같은 순서.
- 전자칠판: 6장 표시, 처음·끝 이동 제한, 키보드 이동, 전체 화면 미지원 안내, 참조 파일 및 QR 자산 존재.
- 문서 구조: `docs/public/`과 문서 안내는 공개용, `docs/private/` 두 문서는 Git 추적 제외. 새 문서는 공개 폴더에 두기 전까지 기본 제외.
- 개인정보: 현재 파일과 로컬 Git 이력에서 학생 이름·출석번호·개별 응답·결석 정보의 연결 기록을 찾지 못함. 유지 요청된 Padlet 제출 링크와 학생 접속 QR 주소는 운영 정보로 구분.

## 검사 명령

```powershell
node --check app.js
node --check config.js
node --check teacher.js
node tests/check.mjs
node tests/teacher.mjs
git diff --check
git ls-files docs
git check-ignore -v docs/private/SURVEY_RESULTS.md docs/private/SURVEY_GROUPS.md
```

두 Node 테스트는 상태·이벤트를 검사하는 DOM 대체 환경을 사용합니다. 실제 브라우저 렌더링이나 Canva·Padlet 계정 조작을 대신하지 않습니다.

## 수업 기기에서 확인할 항목

1. 실제 iPad 10세대 Safari의 가로·세로·화상 키보드에서 잘림, 글꼴, 터치 영역 확인.
2. 학교 계정에서 Canva Docs 생성·편집 초대·두 아이패드의 공동 편집 확인. 3번은 1번 화면을 함께 보며 참여.
3. 5단계 요청문을 문서로 복사하고 2번이 Canva Code에서 구현·게시할 수 있는지 확인.
4. 공유 문서의 게시된 실행 링크를 1번에서 시험하고, 수정 요청·재게시·재시험까지 확인.
5. 8단계에서 최종 실행 주소·반·팀 이름·내용을 먼저 확인하고, 제출 양식 탭을 오가며 각 칸에 붙여 넣기.
6. 제출 중 Padlet 수동 검토와 제출 후 확인·재제출 설정으로 다른 팀 글이 노출되지 않는지 학생 기기 두 대로 확인.
7. 교사가 승인·공개한 뒤 감상 링크 안내. Commenter 권한에서 댓글·좋아요를 확인하고 감상 종료 후 필요하면 Reader로 전환.
8. 시스템 복사가 실패할 때 선택 복사 대안, Safari 기록 다운로드, 새로고침 후 기록 복원 확인.
