# 문서 공개 및 로컬 보관 기준

GitHub에 올릴 문서는 `public/`, 올리지 않을 자료는 `private/`에 보관합니다. `.gitignore`는 이 안내와 `public/`만 업로드 대상으로 허용합니다. `docs/` 바로 아래에 새로 만든 다른 파일·폴더는 기본적으로 제외됩니다.

| 구분 | 파일 | 내용 |
| --- | --- | --- |
| GitHub 공개 | `public/TEACHER_GUIDE.md` | 일반 수업 운영과 Canva 공동 작업 안내 |
| GitHub 공개 | `public/DESIGN_LOG.md` | 앱 설계와 제작 기록 |
| GitHub 공개 | `public/VALIDATION.md` | 검증 결과와 확인할 항목 |
| 로컬 보관 | `private/SURVEY_RESULTS.md` | 현재는 익명 설문 집계. 학급 자료로 분류하여 업로드 제외 |
| 로컬 보관 | `private/SURVEY_GROUPS.md` | 현재는 일반 조 편성 기준. 조 편성 관련 자료로 분류하여 업로드 제외 |

학생별 응답·번호·출결·조 배정, 연락처·계정 정보, 교사용 비공개 링크를 담는 새 자료도 `private/`에 보관합니다. 공개용으로 검토한 일반 안내만 `public/`에 넣습니다. 삭제한 개인정보 원문은 복원하지 않습니다.

`private/`는 Git 업로드 제외 경로이며 접근을 잠그거나 암호화하는 기능은 없습니다. 폴더 전체를 압축해 전달하거나 Git을 거치지 않고 배포할 때도 `private/`를 제외합니다.

기존에 Git이 추적하던 로컬 보관용 파일은 추적 대상에서도 제거해야 합니다. 이 변경을 커밋·푸시하면 최신 저장소에서는 제외되지만, 이미 공개된 과거 커밋에서 자동으로 지워지지는 않습니다.
